# Matrix Mail Organizer

Matrix Mail Organizer is a private email-filing tool operated by Ken Schlenker for his own authorized mailboxes. Its Google authorization screen identifies it as **gws-cli — Matrix Mail Organizer**.

The organizer files messages in the Purchases, Social, Updates, Forums, and Promotions categories into **Marketing/Review**, removes them from the inbox, and adds a sender-specific label. It creates new sender labels as needed and preserves existing receipt labels and read/unread status.

The service is designed to run on the operator’s private server, with recurring checks approximately every five minutes. This public website provides app information only; it does not provide mailbox access, accept email uploads, or offer public registration.

## Google account access

Each account owner authorizes access through Google. The organizer requests Gmail modification access because it must read message metadata and create or apply labels. Although Google’s permission grants broader capabilities, this organizer does not send email, read message bodies or attachments, or permanently delete messages.

The organizer uses sender headers, message identifiers, existing labels, and Google category search results. It stores authorization credentials and filing checkpoints on the private server. See the [privacy notice](privacy.html) for details.

## Control and support

Access can be revoked in [Google Account connections](https://myaccount.google.com/connections). Filing rules can be stopped by the operator. Previously applied labels remain in Gmail until changed.
